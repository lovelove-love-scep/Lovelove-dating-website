# Lovelove — стартовый проект

Адаптивная стартовая страница международного сайта знакомств. В проекте уже есть:
- адаптивный дизайн для телефона и компьютера;
- демонстрационные карточки анкет;
- поиск по имени/городу и фильтр города;
- окно регистрации/входа с проверкой формы;
- подготовленный SQL для профилей и базовой очереди жалоб;
- заготовка подключения Supabase Auth.

**Честное ограничение:** до настройки Supabase регистрация не сохраняет аккаунты, лайки не сохраняются, а анкеты — демонстрационные. Не публикуйте сайт как готовую платформу знакомств до реализации приватных сообщений, модерации, удаления аккаунта и проверки безопасности.

## 1. Откройте проект

1. Скачайте и распакуйте архив.
2. Откройте `index.html` в браузере для осмотра оформления. Для корректной работы JavaScript-модулей лучше запустить через локальный веб-сервер или GitHub Pages/Cloudflare Pages.
3. Самый простой путь для новичка: создать бесплатный аккаунт на GitHub, загрузить эти файлы в новый репозиторий, затем подключить репозиторий в Cloudflare Pages.

## 2. Создайте GitHub с нуля

1. Откройте https://github.com/ и нажмите Sign up.
2. Подтвердите почту.
3. Создайте репозиторий, например `lovelove`.
4. Если GitHub спрашивает публичный или приватный — для сайта можно выбрать Public, но не загружайте туда пароли, личные данные и секретные ключи.
5. Загрузите файлы проекта (`index.html`, `styles.css`, `app.js`, `schema.sql`, `README.md`) через Add file → Upload files → Commit changes.

## 3. Опубликуйте статический сайт бесплатно

1. Откройте https://pages.cloudflare.com/ и создайте аккаунт.
2. Выберите подключение к GitHub и разрешите доступ к репозиторию `lovelove`.
3. Выберите репозиторий и настройки статического сайта. Build command оставьте пустой; папка публикации — корень `/` (или `.` если интерфейс требует значение).
4. Нажмите Deploy. Cloudflare выдаст адрес вида `имя-проекта.pages.dev`.
5. Проверьте сайт на телефоне и компьютере.

На этом этапе это **публичная демо-страница**, не готовый сервис с реальными анкетами.

## 4. Создайте Supabase

1. Откройте https://supabase.com/ и зарегистрируйтесь.
2. Создайте новый проект. Запишите пароль базы в надёжное место; не добавляйте его в `app.js` или GitHub.
3. В панели проекта откройте SQL Editor → New query.
4. Скопируйте содержимое `schema.sql`, вставьте в редактор и нажмите Run.
5. В Project Settings → API (или Connect, в зависимости от интерфейса) найдите Project URL и публичный publishable key / anon key.
6. В `app.js` замените пустые значения:
   ```js
   const SUPABASE_URL = "https://ВАШ-ПРОЕКТ.supabase.co";
   const SUPABASE_ANON_KEY = "ВАШ-ПУБЛИЧНЫЙ-АНОН-КЛЮЧ";
   ```
   В браузере допустим только публичный ключ проекта. **Никогда не вставляйте `service_role` или secret key** в клиентский код.
7. Сохраните и загрузите обновлённый `app.js` в GitHub. Cloudflare Pages должен пересобрать сайт автоматически.
8. В Supabase Authentication настройте подтверждение почты и URL перенаправления для локального тестирования и домена Pages. Используйте точный адрес сайта.

## 5. Что проверить

- Регистрация с корректным email и паролем длиной минимум 8 символов.
- Подтверждение email (если включено).
- Вход с созданным аккаунтом.
- В Supabase → Table Editor → `profiles` появляется строка профиля.
- В браузерном коде отсутствует `service_role`/secret key.
- В настройках базы включён RLS; политики не дают пользователю изменять чужую анкету.

## 6. Следующий этап разработки

После подключения регистрации не запускайте рекламу и платные подписки сразу. Сначала реализуйте и протестируйте:
1. Редактор своей анкеты (имя, возраст 18+, город, био, интересы).
2. Загрузку изображений в Storage с ограничением размера/формата и продуманными правилами доступа.
3. Приватные сообщения с таблицами бесед/участников и RLS, чтобы переписку могли читать только участники.
4. Лайки и совпадения с ограничением уникальности.
5. Жалобы, блокировки, модераторский процесс и удаление аккаунта.
6. Политику конфиденциальности, условия использования, правила контента и контакт для жалоб.
7. Только потом — платёжного провайдера, налоги, возвраты и Premium.

## Стоимость

На старте можно стремиться к €0 за хостинг и бесплатные лимиты базы. Однако это не обещает постоянных нулевых расходов: собственный домен, увеличение квот, email, безопасность, модерация и обработка платежей могут стоить денег. Проверь актуальные лимиты тарифов перед запуском.
